# Security

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/yagipass/homebrew-tap/security/advisories/new). Do not open a public issue.

## Supported versions

Only the formulas on `main` receive security fixes.

## Scope

This repository holds the formulas and the `bump.yml` workflow. Report a vulnerability in a tool itself to that tool's repository: [ajmx](https://github.com/yagipass/ajmx/security/advisories/new), or [Verbatime](https://github.com/yagipass/verbatime/security/advisories/new) for `vbtm`.
